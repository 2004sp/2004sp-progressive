15. Plugins

A dedicated page from the 2004scape Progressive build 254 coverage audit.

This list mirrors every entry in the launcher's Custom Content menu. From the launcher main menu choose 14, enter a plugin number to toggle it, use A to enable all, D to disable all, and B to return. Starting the matching server path after a change rebuilds the content pack where required and reloads the selected environment settings.

Admin commands used below: item spawning requires administrator level 3 or higher and uses ::give <item_debug_name> [amount]. Commands and item names are case-insensitive.

How plugin toggles work (start here)

New to this? Read this first. A "plugin" on this page isn't a separate add-on file — it's just optional code that's already sitting inside the server, wrapped in a check like "is this switch turned on?". That switch is an environment variable: a named setting (e.g. NODE_FEATURE_CLANS) stored in a plain-text file called .env inside the engine folder. Set it to true and the feature runs; set it to false (or delete/comment out the line) and the server behaves as if that code doesn't exist. Nothing needs to be recompiled to flip a switch — only the server needs a restart to pick up the new value.

A. Toggle an existing plugin (easy way)

Use the launcher menu — no file editing required.

  1. Run the launcher (node launcher.ts, or your platform's start script) from the engine folder.
  2. At the main menu, enter 14 for Custom Content.
  3. Each line shows a number, a plugin name, its flag in brackets, and whether it's enabled or disabled.
  4. Type the number of the plugin you want to flip and press Enter. Repeat for as many as you like.
  5. Type A to turn everything on, D to turn everything off, or B to go back to the main menu when you're done.
  6. Start (or restart) the launcher path that owns the setting. The five startup QOL controls numbered 10–14 below are intentionally honored only by option 2, Custom Server + Hiscores; options 1 and 3 do not activate them.

Under the hood this just rewrites the matching line in engine/.env for you — see option B if you'd rather do that by hand.

B. Toggle it by hand (advanced)

Open engine/.env in a text editor. If it doesn't exist yet, copy engine/.env.example to engine/.env first.

Find (or add) the line for the flag you want and set it explicitly:

NODE_FEATURE_CLANS=true

Save the file and restart the server. That's the entire mechanism — the launcher's menu in option A is just a friendlier way of editing the same line.

Two kinds of switch, one habit to remember: most flags below default to off until you set them to true (e.g. NODE_FEATURE_CLANS). A few interface-level ones read live from a script and default to on until set to false — those are called out individually in the catalogue below. When in doubt, check the plugin's card.

Launcher scope for the new startup QOL controls: option 1 is Start Server and remains the vanilla path. Option 2 is Custom Server + Hiscores and is the only launcher path that honors NODE_ANTI_RANDOM_EVENTS, NODE_QOL_SCROLLWHEEL_ZOOM, NODE_QOL_ANTI_MACRO_ROTATION, NODE_QOL_AUTO_OPEN_WEBCLIENT, and NODE_QOL_AUTO_OPEN_HISCORES. Option 2 serves hiscores from the custom server's normal web listener at /index.html (using WEB_PORT) rather than starting the separate port-3000 hiscores process. Option 3, Start Server + Hiscores, keeps its vanilla server plus separate hiscores-service behavior, and option 4, Run Hiscores in background, is unchanged.

Adding a brand-new plugin toggle (for scripters)

Everything above assumes the plugin already exists. This section is for anyone writing new content who wants it to be optional. There are two ways to gate code behind a flag, depending on where that code lives. Both are demonstrated here with a made-up example: a "Double Drops" weekend toggle.

Gating a content script (most common)

If the code you're adding lives in a .rs2 content script, use the built-in map_feature(name) command. It reads NODE_FEATURE_<NAME> from the environment every time it's called — no engine changes and no restart-to-edit-a-script needed, and it defaults to enabled if the variable is unset.

  1. Pick a short lowercase name, e.g. doubledrops.
  2. Wrap the new behaviour in an if check inside your script:

if (map_feature("doubledrops") = true) {
    // double the roll here
}

  1. Add a documented, disabled-by-default line to engine/.env.example:

## NODE_FEATURE_DOUBLEDROPS=false

  1. Done. Server owners flip it on with NODE_FEATURE_DOUBLEDROPS=true in their own .env — the change takes effect on next login/action, no rebuild required.

Real example: content/scripts/login_logout/login.rs2 gates the Custom Shops NPC spawn with map_feature("customshops").

Gating engine (TypeScript) code

If the feature touches core server systems instead of a script — a new manager, a background loop, a database table — wire it through engine/src/util/Environment.ts instead. This is read once at startup, so toggling it does need a restart.

  1. Add a line to Environment.ts, defaulting to disabled:

NODE_FEATURE_DOUBLEDROPS:
  tryParseBoolean(process.env.NODE_FEATURE_DOUBLEDROPS, false),

  1. Check it wherever the subsystem starts up or runs:

if (!Environment.NODE_FEATURE_DOUBLEDROPS) {
    return; // feature disabled, stay fully hidden
}

  1. (Optional) Add it to the launcher's menu so it's toggleable from option 14 — append an entry to the customContent list near the top of engine/launcher.ts:

['Double Drops', 'NODE_FEATURE_DOUBLEDROPS'],

Real example: the clan system (engine/src/engine/clan/ClanManager.ts) is gated this way behind NODE_FEATURE_CLANS.

Gameplay plugins

1. Clans

How to use it: type ::clan to open the clan menu. A player outside a clan can create one or join by entering its exact name. Clan names must be 2–15 characters and may contain letters, numbers, spaces, and underscores. Members can view the member list and roles, while higher ranks can promote, demote, kick, mute, and manage the clan according to the configured role permissions.

Chat commands: type /clan in normal chat to switch to clan chat and /world to return to world chat. The command-box equivalents are ::chatclan, ::clanmsg <message>, and ::chatworld. Clan messages show the clan name and the sender's role: Member, Helper, Mod, Admin, or Owner.

The filter: messages are unpacked and passed through the server's bad-word, domain, fragment, and top-level-domain word filter before either world or clan delivery. A clan mute is separate from that automatic filter: a permitted clan rank can prevent a lower-ranked member from speaking in clan chat until unmuted.

Feature flag: NODE_FEATURE_CLANS.

2. Custom Shops

Where to find it: trade Callum in the Varrock area at world coordinate 3283, 3386, level 0. His shop is titled Callum's Prestigious Wares.

What he sells: all 19 skillcapes for 99,000 coins each, plus Bunny Ears and a Scythe for 1,000,000 coins each. The shop stocks ten of each cape and five of each rare item. It does not buy items from players.

Feature flag: NODE_FEATURE_CUSTOMSHOPS.

3. Boss Pets

How to get them: defeat the matching boss. King Black Dragon and Kalphite Queen each roll their pet at 1/10,000; Chaos Elemental, Giant Mole, and Scorpia each roll theirs at 1/5,000. If you have no follower, the pet spawns beside you automatically. If you already have a follower, its item is placed in your inventory when space is available.

BossAdmin item command
King Black Dragon::give kbd_pet_item
Kalphite Queen::give kq_pet_item
Chaos Elemental::give chaos_elemental_pet_item
Giant Mole::give baby_mole_item
Scorpia::give scorpia_pet_item

How an admin spawns one: run the matching ::give command, then choose Drop on the pet item. The item is consumed and the pet becomes your follower. Only one follower may be active at once; pets can be picked up, stroked, told to stay/follow, or shooed away.

Feature flag: NODE_FEATURE_BOSSPETS.

4. Custom Weapons

How to get them:

  • Dragon pickaxe — dropped by the Chaos Elemental. The source has a dedicated 1/1,000 roll and also includes it in one slot of the boss's 128-entry main table. Requires 61 Mining to use as a pickaxe.
  • Dragon axe — 1/1,000 drop from the Giant Mole. Requires 61 Woodcutting to use as an axe.
  • Dragon 2h sword — 1/1,000 drop from Scorpia. Requires 60 Attack to wield.

Admin spawn commands: ::give dragon_pickaxe, ::give dragon_axe, and ::give dragon_2h_sword.

Feature flag: NODE_FEATURE_CUSTOMWEAPONS.

5. Skillcapes

How to get them: buy the cape for your skill from Callum at 3283, 3386, level 0 for 99,000 coins. A base level of 99 in the matching skill is required to wear it. Use the cape's Play emote inventory option to perform its custom animation and graphic.

Admin spawn names:

agility_skill_cape, fishing_skill_cape, attack_skill_cape, crafting_skill_cape, defence_skill_cape, fletch_skill_cape, herblore_skill_cape, hitpoints_skill_cape, magic_skill_cape, mining_skill_cape, prayer_skill_cape, ranging_skill_cape, runecraft_skill_cape, smithing_skill_cape, strength_skill_cape, thieve_skill_cape, cooking_skill_cape, firemaking_skill_cape, woodcutting_skill_cape

Prefix any one with ::give; for example, ::give attack_skill_cape.

Feature flag: NODE_FEATURE_SKILLCAPES.

Interface and quality-of-life plugins

6. X-Amount Shop Input

Open any shop, right-click the item you want to buy and choose Buy X, or right-click an inventory item while the shop is open and choose Sell X. Enter the amount in the number box and confirm it. The script caps a single Buy-X or Sell-X request at 500.

Feature flag: NODE_FEATURE_XAMOUNT.

7. Make-X Skill Actions

Begin a supported production action while carrying multiple sets of materials, then choose Make X or use the displayed quantity prompt. Enter the number to make and confirm. The action repeats until that count is reached, you run out of materials, or another requirement stops the action.

Verified supported examples include cutting logs for Fletching, Cooking, cutting gems, brewing potions, smelting bars, and filling containers at water sources.

Feature flag: NODE_FEATURE_MAKEX.

8. Middle-Mouse Button Rotation

Move the pointer over the game view, hold the middle mouse button, and drag. Horizontal movement rotates camera yaw; vertical movement changes camera pitch. Release the button or move the pointer outside the game canvas to stop rotating.

Feature flag: NODE_QOL_MIDDLE_MOUSE_ROTATION.

9. Left Click Compass Reset

Left-click or tap the compass above the minimap. The camera snaps to north and returns to its default pitch. The reset briefly holds the camera in place so the click cannot immediately drag it away again.

Feature flag: NODE_QOL_COMPASS_RESET.

10. Anti Random Events

When enabled under launcher option 2, this blocks Random/AFK events by making the AFK_EVENT opcode report 0 instead of allowing a ready event to fire. The existing readiness flag is still cleared after the check.

With the flag disabled, the vanilla event-rate, chance, readiness, and opcode behavior remain unchanged. Launcher options 1 and 3 force this plugin off even if the variable is true, preserving vanilla Random/AFK event behavior on those paths.

Feature flag: NODE_ANTI_RANDOM_EVENTS. Default: false. Scope: option 2 only.

11. Anti-Macro Camera Rotation

When enabled under launcher option 2, this suppresses the vanilla slow anti-macro camera rotation and the periodic camera nudge that feeds it. It does not disable normal arrow-key/manual yaw or pitch controls, middle-mouse rotation, compass reset, or the separate minimap anti-macro drift.

Launcher options 1 and 3 force this plugin off even if the variable is true, preserving their vanilla camera behavior.

Feature flag: NODE_QOL_ANTI_MACRO_ROTATION. Default: false. Scope: option 2 only.

12. Auto-Open Web Client

When enabled under launcher option 2, the launcher waits until the custom server's web listener is reachable and then opens the webclient route at /rs2.cgi. The URL uses the configured WEB_PORT instead of assuming port 80.

Options 1 and 3 ignore this flag and never auto-open the webclient from it.

Feature flag: NODE_QOL_AUTO_OPEN_WEBCLIENT. Default: false. Scope: option 2 only.

13. Auto-Open Hiscores

When enabled under launcher option 2, the launcher waits for the custom server's main web listener and hiscores API to be ready, then opens /index.html on the configured WEB_PORT. On the default Windows port 80, that page is http://localhost/index.html.

Option 2 does not start the separate port-3000 hiscores process. Option 3 keeps its existing separate hiscores-service behavior, and options 1 and 3 ignore this auto-open flag. If both auto-open flags are enabled for option 2, hiscores opens first and the webclient follows through the same default-browser session.

Feature flag: NODE_QOL_AUTO_OPEN_HISCORES. Default: false. Scope: option 2 only.

14. Mouse Scrollwheel Zoom

When enabled under launcher option 2, move the pointer over the game canvas and scroll the mouse wheel to adjust the normal in-game camera distance. Wheel up zooms in one step and wheel down zooms out one step. Wheel input is normalized by direction, using a 64-unit step and clamping camera distance to 768..2048.

The wheel event is consumed only while the plugin is enabled and actively handling normal in-game camera zoom. Login/loading states and cinematic camera control are left untouched, while page scrolling outside the game canvas continues normally. Launcher options 1 and 3 force the plugin off even if .env or start.bat sets the flag to true.

Feature flag: NODE_QOL_SCROLLWHEEL_ZOOM. Default: false. Scope: option 2 only.
