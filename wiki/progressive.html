12. Progressive-only additions

A dedicated page from the 2004scape Progressive build 254 coverage audit.

Everything below is Progressive's own layer on top of the Lost City base — none of it existed in real 2004 RuneScape as a player-facing mechanic, though the hiscores concept mirrors a real website feature of the era.

Bot AI

A genuinely large system: BotPlayer, BotGoalPlanner, BotKnowledge, BotManager, BotNeeds, plus 23 individual task modules covering Woodcutting, Mining, Fishing, Combat, Firemaking, Cooking, Smithing, Thieving, Crafting, Ranged/Magic, Runecrafting, Fletching, Herblore, Agility, bank-standing, flax-picking, water-filling, social interaction, vendor trips, shop trips, and two separate PKing behaviors (general wilderness + Edgeville-specific). Four weighted personality archetypes (Skiller, Fighter, Balanced, Random) pick tasks; bots.config.json configures 100 bot accounts.

Broad, with real gaps

  • Bots never touch the (fully implemented) quest system — no quest-related logic anywhere in the goal planner.
  • No dedicated Prayer-training task — the only prayer-related bot behavior is opportunistic bone-burying, not altar training.

Hiscores

A real SQLite-backed HTTP API (/api/hiscores, per-skill, per-player) serving overall and individual skill rankings. Real RuneScape did have official website hiscores by 2004, so this recreates a genuine period feature rather than inventing one — serving it as a local REST endpoint is Progressive's own implementation choice.

Functional

The web client and Java client present in the Server tree are inherited wholesale from the upstream Lost City project, not authored by Progressive — they weren't deeply re-audited for this report.
