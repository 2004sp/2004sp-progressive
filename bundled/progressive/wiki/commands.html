16. Commands

Every supported player, staff, client and dedicated developer-test command found in the current source tree.

Type ordinary commands with ::. Scripted debug procedures use ::~ by default because NODE_DEBUGPROC_CHAR defaults to ~. Debug procedures require developer level 4 and are disabled in production. Production-only moderation commands are unavailable on a local development world.

Warning: many administrator and developer commands permanently clear inventories, banks, quests, variables, or account progress. Test them only on disposable accounts and worlds. A name appearing here does not grant permission to use it.

Scope: this catalogue covers every command implemented by the core server handler, the Java client, all three dedicated RS2 debug-command suites, and every additional [debugproc] embedded elsewhere in the source tree. Aliases that perform the same action are grouped together.
