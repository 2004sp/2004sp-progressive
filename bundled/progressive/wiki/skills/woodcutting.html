Woodcutting gathers logs from trees for skills such as Firemaking and Fletching. At the 7 September 2004 cutoff, the standard progression runs from normal trees through Oak, Willow, Maple, Yew and Magic, with members also able to cut Achey trees from the pre-cutoff Ogre content. Axes are deliberately unusual in this period: Woodcutting level does not gate axe tiers, so a player can chop with any supported axe they can carry; normal equipment requirements only matter if the axe is being wielded.

How Woodcutting works

Basic loop: choose Chop down on a supported tree while carrying or wielding an axe. The build checks the tree's Woodcutting requirement and inventory space, chooses the best supported axe available, performs a skill-success roll, then awards the tree's configured XP and log product on success.

  • Tree level is the main skill gate: the chopping handler compares the player's current Woodcutting stat with the tree's configured requirement. The tables below record the normal base-level unlocks.
  • An axe can be worn or carried: build 254 accepts an axe in the right-hand equipment slot or anywhere in the inventory.
  • The best available axe is selected automatically: the handler tests Rune, Adamant, Mithril, Black, Steel, Iron and Bronze in that order. You do not need to manually choose a weaker axe if a better supported one is present.
  • No Woodcutting-level axe requirements: the source contains later-style axe checks but comments them out, explaining that those requirements were not part of the 2004 behaviour. This means a high-tier axe can still be used from the inventory at low Woodcutting levels.
  • Success is a skill roll, not a fixed percentage: each supported tree and axe tier supplies low/high values to the engine's stat_random routine. Higher axe tiers use stronger values, but those configuration numbers should not be presented as literal chop percentages.
  • Inventory space matters: the standard handler requires one free inventory slot before beginning the chopping attempt.
  • Tree depletion varies: Oak, Willow, Maple, Yew and Magic rows use a one-in-eight depletion check after a successful log. Normal and Achey trees use the separate normal-like single-success depletion path.
  • Respawn values are scaled: the configured tree respawn value passes through the project's player-count scaling routine. Raw configuration numbers are therefore not presented here as fixed real-time seconds.

Axes

The supported chopping axes form an efficiency ladder rather than a Woodcutting-level unlock ladder. Build 254's tree data gives progressively stronger success-roll parameters to higher tiers, and the chopping script chooses the strongest supported axe it finds.

Carrying versus wielding: the Woodcutting action does not apply those Attack requirements. Build 254's axe checker accepts the best supported axe in the inventory even when the player cannot wield it, so a level-1 Attack player can still chop with a carried Rune axe. The Attack values above apply only when equipping the axe in the right hand.

Training methods

The build evidence gives exact requirements, per-log XP and relative axe success parameters, but it does not establish a historically exact XP-per-hour route. The route below is therefore a conservative progression through verified cutoff content rather than a claim about one universally optimal training method.

Axe choice: regardless of tree, carry the strongest supported axe available to you. The build's success-roll values improve at every axe step from Bronze through Rune, while Woodcutting level does not prevent a low-level woodcutter from using the better axe from the inventory.

2004scape implementation notes

Core implementation: scripts/skill_woodcutting/scripts/woodcut.rs2 handles axe detection, membership/product checks, the Woodcutting requirement, success rolls, XP, products, depletion and respawning. scripts/skill_woodcutting/configs/trees.dbrow supplies the supported tree rows and their requirements, XP and axe-specific success parameters.

  • Axe requirements are deliberately disabled: woodcut.rs2 retains the later-style Woodcutting requirement checks as comments but does not execute them. The source comment points to a preserved 22 June 2004 RuneHQ Woodcutting guide as historical evidence that axe tiers did not have Woodcutting requirements in the target-era behaviour.
  • Axe priority: the chop handler searches Rune → Adamant → Mithril → Black → Steel → Iron → Bronze and uses the first supported axe found, whether worn in the right hand or carried in inventory.
  • XP scale: the core cutoff rows use internal product-XP values of 250, 375, 675, 1000, 1750 and 2500 for normal/Achey, Oak, Willow, Maple, Yew and Magic respectively, equal to 25, 37.5, 67.5, 100, 175 and 250 displayed XP.
  • Success parameters are not percentages: trees.dbrow stores axe-specific low/high values that are passed into stat_random. The higher values on better axes establish relative improvement; this page intentionally does not turn them into unsupported fixed chop-rate percentages.
  • Depletion: the standard Oak-through-Magic rows use deplete_chance=8, producing a one-in-eight depletion test after a successful log. Normal-like zero-respawn rows use the script's separate single-success depletion path.
  • Respawn scaling: configured respawn values are passed to scale_by_playercount, so this guide does not label the raw values as exact wall-clock seconds.
  • Membership nuance: the script checks the chopped product's members flag before awarding it on a free world. Some period members-only tree access, especially Maple sourcing, is also a world-location restriction rather than a property of the log item itself.
  • Level-up file contains later content: scripts/levelup/scripts/levelup_unlocks_woodcutting.rs2 currently includes the level-40 Fremennik Trials requirement. That row is useful evidence of the current build but is not valid for the 7 September 2004 historical unlock table.

Cutoff exclusions

Current checkout does not equal the historical snapshot: later content can exist in build-254 data and level-up messages even when it had not been released by 7 September 2004. These entries are intentionally kept out of the historical progression and training tables.

  • Hollow trees and bark: the current Woodcutting database contains a level-45 Hollow-tree row awarding 82.5 XP and Hollow bark, but Hollow trees belong to the 18 October 2004 Shades of Mort'ton / Splitbark-era update and are after the cutoff.
  • The Fremennik Trials level-40 requirement: the current level-up script advertises this milestone, but The Fremennik Trials was released on 2 November 2004, so the old wiki row has been removed from the cutoff unlock table.
  • Later Woodcutting-level axe gates: later-era axe requirements are not back-applied to the September 2004 snapshot. Build 254 itself leaves those checks commented out and cites period evidence for the no-Woodcutting-requirement behaviour.
